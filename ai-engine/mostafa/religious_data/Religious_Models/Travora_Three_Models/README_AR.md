# نماذج Travora المستخرجة

1. `Islamic_Importance_Model.joblib`: نموذج أهمية إسلامي محفوظ. مقياسه محفوظ في بيانات الإسلام داخل عمود `ml_importance`.
2. `Christian_Content_Model.json` مع `Christian_Ranker.py`: نموذج استرجاع/ترتيب بالمحتوى المسيحي. ملف JSON يحتاج ملف المشغل لقراءة النموذج وتقديم الاقتراحات. ليس مصنفًا مدربًا على Labels للأهمية؛ التدريب الإشرافي متوقف لعدم وجود أحكام بشرية كافية.
3. `Islamic_Trip_Recommender.py`: مشغل توصيات الرحلات الموحد الذي يدعم الإسلام والمسيحية ويخطط المسار والميزانية. هذا كود دمج وتوصية، وليس نموذجًا ثالثًا مدربًا مستقلًا. يستخدم درجة `ml_importance` عندما تكون متاحة، وإلا يعتمد على أوزان قواعدية.

التوافق مع بيانات التشغيل يتطلب تثبيت المكتبات المذكورة في الحزمة الأصلية، واستخدام CSV بأعمدة الدين والإحداثيات والمنطقة المناسبة. لم أغيّر محتويات النماذج.
