# Travora — تحديث شريط التنقل السفلي

يتضمن هذا التحديث ثلاثة ملفات بديلة فقط:

- `lib/app/navigation/travel_bottom_nav.dart`: شريط تنقل عائم بتصميم زجاجي خفيف، زوايا دائرية، تدرج أزرق، توهج للتبويب النشط، وتحريك ناعم للأيقونة والتبويب.
- `lib/main.dart`: نقطة تشغيل التطبيق دون غلاف DevicePreview.
- `lib/app/travora_app.dart`: إزالة ربط DevicePreview.appBuilder حتى لا يظهر شريط Device Preview أسفل المحاكي.

## طريقة التركيب

فك ضغط الأرشيف داخل المجلد الرئيسي لمشروعك مع السماح باستبدال الملفات الثلاثة المناظرة فقط. الأرشيف يحتوي هذه الملفات الثلاثة ولا يحتوي بقية المشروع؛ لذلك لن يحذف أو يستبدل `pubspec.yaml` أو مجلدات `ios` و`android` أو بقية ملفات `lib`.

بعد فك الضغط، نفّذ من جذر المشروع:

```bash
flutter pub get
flutter analyze
flutter run
```

## ملاحظات

- ترتيب التبويبات ووجهاتها وأرقام `selectedIndex` لم تتغير:
  - `0`: حسابي
  - `1`: رحلاتي
  - `2`: التخطيط
  - `3`: الخدمات
  - `4`: الرئيسية
- لا توجد حزمة إضافية مطلوبة للتصميم؛ التأثيرات مبنية باستخدام Flutter SDK فقط.
- يزيل التحديث تكامل DevicePreview من تشغيل التطبيق، لكنه لا يحذف الحزمة من `pubspec.yaml`.
- لم يتم تنفيذ `flutter analyze` أو `flutter run` في بيئة إعداد الأرشيف لعدم توفر Flutter SDK بها.
